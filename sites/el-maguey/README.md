# Bungalows El Maguey — website

Static one-page site for Bungalows El Maguey (Calle Bugambilias 3, Zicatela, Puerto Escondido).
No build step: open `index.html` or deploy the folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages).

## Features
- Sections: hero, the bungalows, property (rooftop / garden & pool / gym), experiences, reviews, location map, booking
- English / Spanish toggle (auto-picks Spanish for Spanish-language browsers)
- Availability form that composes a WhatsApp or email message with dates, guests and name
- Direct links to WhatsApp, email, bookeddirectly.com and the Airbnb listing
- Schema.org `LodgingBusiness` markup for Google

## Adding photos
Drop JPGs into `images/` with these names. Until a file exists, a sunset-gradient placeholder shows in its place.

| File | Suggested shot |
|---|---|
| `hero.jpg` | Rooftop palapa / ocean at sunset (wide, ≥ 2000px) |
| `garden.jpg` | Garden deck and pool (portrait) |
| `bungalow-1.jpg` | Bungalow bedroom (wide) |
| `bungalow-2.jpg` | Kitchen |
| `bungalow-3.jpg` | Balcony with hammock |
| `bungalow-4.jpg` | Bathroom |
| `rooftop.jpg` | Rooftop palapa with hammocks |
| `pool.jpg` | Pool / ice bath |
| `gym.jpg` | Gym & Pilates reformer |

Keep each under ~400 KB (export at ~80% JPEG quality) so the page loads fast on mobile.
