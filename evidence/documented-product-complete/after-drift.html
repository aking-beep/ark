SEC-04Scope every tool credential to the narrowest permission that works. One service account per tool, not one per agent.

SEC-05Human approval gate on: Issue refund (above the stated value ceilings).

SEC-06Treat all retrieved and user-supplied content as untrusted data, never as instructions. Test with an adversarial injection suite in CI.

Prompt injection is not a prompt-engineering problem; it is an architecture problem solved by privilege separation.

Control correlates injection-signature detections with subsequent tool calls.blocking
SEC-07Log every model call with workload, user, model, tokens, cost, latency, outcome and any action taken.
