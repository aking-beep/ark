# GitHub Launch Plan

## Repository positioning

**AI Fit Engine**
> An open behavioral recommendation engine for matching people to AI products, models, workflows, and portable working configurations.

## What makes the repo useful to developers

- scoring engine
- extensible AI product registry
- extensible model registry
- scenario framework
- explainable fit engine
- portable persona exports
- benchmark/eval hooks

## Community model

Accept contributions for:
- registry records
- public benchmark results
- scenario packs
- export adapters

Do not accept:
- unsupported vendor claims
- affiliate links inside registry data
- psychological profiling labels
