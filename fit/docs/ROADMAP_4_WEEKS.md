# Four-Week Build Roadmap

## Week 1 — Engine before interface

### Deliverables
- data models
- scenario schema
- event schema
- behavioral metric engine
- user fit vector
- product registry loader
- model registry loader
- fit algorithm
- CLI
- tests

### Exit criteria
A sample session can produce ranked product/model recommendations entirely from local data.

## Week 2 — API + credible recommendations

### Deliverables
- FastAPI service
- 8 scenario definitions
- evidence tracking
- confidence
- persona generator
- export adapters
- registry validator
- fit regression tests
- seed registry expansion

### Exit criteria
API can drive a complete assessment without frontend-specific business logic.

## Week 3 — Game UI

### Deliverables
- landing page
- assessment flow
- scenario cards
- free text + choices
- progress
- results dashboard
- product match cards
- model match by workload
- AI stack visualization
- persona export

### Exit criteria
A user can complete the game end-to-end in-browser.

## Week 4 — Evaluation + public beta

### Deliverables
- model/product evaluation harness
- registry freshness tooling
- optional LLM event classifier
- analytics
- privacy copy
- README screenshots
- hosted beta
- GitHub launch material
- first 25 user test sessions

### Exit criteria
Recommendations are explainable, registry claims are dated, and user feedback can be collected.

## After v0.1

- accounts and persistent profiles
- product comparison mode
- team/enterprise assessment
- registry update automation
- community-contributed evals
- API/SDK
- MCP integration
- longitudinal adaptation from real interactions
